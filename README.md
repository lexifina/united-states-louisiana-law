# Louisiana: law history in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law), one git history for every country's law: this is the law of Louisiana, United States, which global-law reads at `united-states/louisiana/acts/`.

The statute law of Louisiana as a git repository: one file per section, committed with the official publisher named as author. It follows the shared design of [lexifina/global-law](https://github.com/lexifina/global-law).

## Where the text comes from

The text is read from **Louisiana Laws** on <https://legis.la.gov/>, published by the **Louisiana State Legislature**. The Legislature notes that the provisions are provided for information and are not official or authoritative; this repository carries them as published there. Each section keeps its text and the Act citations that close it. Annotations are not taken. The House, Senate and Joint Rules, which the same site publishes, are chamber rules and are not taken.

## Dates

- Each act has **one version**: the first build's four acts are dated 29 October 2026, the last full day before their pages were retrieved on 30 October 2026; every later act is dated the day its pages were retrieved (November 2026). The site prints no edition date. It is the oldest version available: the Legislature publishes the current text only.
- The first commit of each act is credited to the Louisiana State Legislature as "oldest version available".
- The Act citations in each section are part of the text, not the commit dates.

## What it does not show

- Reconstructed earlier consolidated code versions; the historical session-law records described below are separate texts.
- Any title or code whose pages are not yet all retrieved (see the table above for what is in).
- Regulations (the Louisiana Administrative Code) and the chamber rules.
- Nothing here is an official publication.

## How it is checked

- Every unit is read back from git on its day and compared with the corpus (`tools/check_repo.py`; results in `REPRODUCE.md`).
- Each source file is identified by its sha256, in `data/versions.json`.

## What "author" means

Each commit is authored by the publisher (the Louisiana State Legislature) because the repository holds one version of each act, the oldest version available. The committer is always Lexifina.

## Historical session laws

This append adds 486 as-enacted acts of the 1997 Regular Session, each as one complete enrolled document. The text is published by the Louisiana State Legislature. Effective dates come from its session effective-date table; the records retain the source document headers and signature labels. Each historical record is added as a labelled correction, without replacing the earlier published commits. The editorial correction commits are authored by Lexifina; the law text comes from the Legislature.

These are session laws, including amending and one-time acts; they are not prior consolidated editions of the codes. Records with unresolved commencement, unavailable enrolled text, graphical content, or conflicting text extraction are excluded. Earlier consolidated code editions and the other legislative sessions remain outside this historical addition.
