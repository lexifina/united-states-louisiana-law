# RS 9:5217. Recorder's fees for multiple indebtedness mortgages; form
The uniform filing fee that a recorder in any parish of this state is authorized to charge for the filing and recordation of a multiple indebtedness mortgage executed in accordance with Civil Code Article 3298 is as set forth in R.S. 13:844.
